# Hark 听录转文字 - 设计文档

日期：2026-06-17

## 目标

做一个 macOS 本地桌面端听录转文字 App，支持同时录制麦克风和外放声音，可选择本地或云端 ASR 模型，支持边录边转和录完再转两种模式。

## 技术栈

- **桌面框架**：Tauri 2 + Vue 3 + TypeScript
- **后端语言**：Rust
- **音频采集**：cpal
- **UI 设计**：frontend-skill（taste-skill），跟随系统深色/浅色模式

## 录音源

提供三种明确选项：

1. **仅麦克风** - 录制说话人声音
2. **仅外放** - 通过 BlackHole 录制系统输出（需用户已安装 BlackHole）
3. **同时录制** - 同时采集麦克风和 BlackHole，混音成单声道 WAV 保存

选择"仅外放"或"同时录制"时，如果检测不到 BlackHole 设备，前端提示用户安装并配置多输出设备。

## 实时音量显示

- 录音期间，Rust 后端每 100ms 计算当前音频块的 RMS 值
- 通过 Tauri event `audio:volume` 推送到前端
- 前端显示动态音量条和分贝数值

## ASR 后端

支持三种后端，用户可切换：

| 后端 | 类型 | 调用方式 | 备注 |
|------|------|----------|------|
| mlx-qwen3-asr | 本地 | Python 脚本 | 用户已安装，Apple Silicon 优化 |
| whisper.cpp | 本地 | 编译后的 `whisper-cli` 二进制 | 用户正在安装 |
| DashScope | 云端 | Python `dashscope` SDK | 需要 API Key |

每个后端封装为独立模块，统一接口：

```rust
async fn transcribe_file(path: &str, config: &AsrConfig) -> Result<String, String>
```

## 转写模式

### 录完再转
- 停止录音后，把完整 WAV 文件送给选定的 ASR 后端
- 结果显示在文本区域

### 边录边转（伪实时）
- 录音过程中，每 5 秒切一个音频片段保存到临时目录
- 片段进入队列，由后台任务依次转写
- 转写结果通过 Tauri event `asr:segment` 推送到前端
- 前端按时间顺序追加显示，形成接近实时的效果
- 切片间隔可在设置中调整（默认 5 秒，范围 3-10 秒）

## 音频格式

- 采样率：保持设备默认（通常 44100 或 48000），转写前按需重采样
- 声道：单声道（录制时取第一个通道并混音）
- 格式：WAV 16-bit PCM

## 状态与事件

Rust 后端维护全局状态：
- 当前是否录音
- 当前录音源
- 当前 ASR 后端
- 是否开启边录边转
- 切片队列

前端通过 Tauri events 接收：
- `audio:volume` - 音量级别 0.0-1.0
- `asr:segment` - 转写文本片段 `{text, start_ms, end_ms}`
- `audio:error` - 录音或转写错误

设计原则：
- **极简但有设计感**：大量留白、克制的色彩、精致的微交互
- 卡片式布局，大按钮，清晰的录音状态反馈
- 跟随系统深色/浅色模式
- 录音中按钮变为红色脉冲效果
- 音量条使用渐变色
- 字体：系统默认无衬线字体，中文使用苹方 / PingFang SC
- 圆角、阴影、过渡动画统一且克制

## 错误处理

- 找不到 BlackHole：提示安装并跳转到 GitHub 下载页
- ASR 后端未安装：提示安装命令
- API Key 为空：转写前校验
- 录音设备被占用：提示检查系统权限或其他应用
